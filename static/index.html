Lấy Stream Key Tự Động (Auto Fetch)

Cách 1: Dán mã Cookie sessionid từ tài khoản TikTok để hệ thống tự động lấy Stream Key.

Hướng dẫn lấy Session ID:
1. Mở tiktok.com trên Chrome, đăng nhập tài khoản có bật Live
2. Nhấn F12 → Tab Application/Cookies → tìm sessionid
3. Copy giá trị (không copy tên cookie, chỉ copy value)
⚠ Yêu cầu: Tài khoản 18+ | 1000+ followers | Đã bật tính năng Live
📺 Cách 2: Lấy từ TikTok Live Studio

1. Truy cập tiktok.com/live/studio → đăng nhập
2. Chuyển sang tab Stream Settings / Stream with OBS
3. Copy RTMP Server URL và Stream Key bên dưới
4. Dán vào form thủ công bên dưới → nhấn LƯU CẤU HÌNH STEAM
